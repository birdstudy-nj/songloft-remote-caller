# 🎙️ 远程呼唤 (Remote Caller) - 小爱音箱趣味互动插件

“远程呼唤”是一个轻量级、跨平台的智能音箱 Web 插件。它允许你在手机或电脑上，通过原生级流畅的界面，向家中的「小爱音箱」发送**原声语音**或**小爱 TTS 播报**。

本项目初衷为**家庭娱乐与互动**，通过公网的控制，让传统的智能音箱秒变“家庭对讲机”和“整蛊神器”！🚀

**⚠️ 重要前提**：由于浏览器安全策略，**麦克风录音功能必须在 `HTTPS` 协议下才能调用**。


## 🎮 趣味应用场景 (Playful Use Cases)

开发本插件不仅是为了技术实现，更是为了给平淡的生活加点料：

- 📻 **家庭对讲机 (Walkie-Talkie)** 身处卧室的你可以直接控制客厅的小爱音箱，客厅的家人也能控制你房间的音箱。无需大声呼喊，“晚饭做好了，快出来吃” —— 瞬间实现跨房间的赛博对讲！
- ⏰ **夺命连环 Call (Morning Wake-up)** 早上赖床起不来？让伴侣或室友在另一间房把你的音箱音量拉满，一键发送原音咆哮：“快起床啦！！！”（注：插件贴心内置了 80% 音量防误触高能预警防线 🛡️）。
- 👻 **搞怪整蛊 (Pranks & Fun)** 夜深人静时，躲在被窝里用小爱 TTS 模式向朋友房间的音箱悄悄发送一句：“我看到你了~”，感受科技带来的“惊喜”。
- 🐱 **远程逗宠 (Pet Teasing)** 不在家时，通过摄像头看着主子，用自己的原声从音箱里呼唤它的名字，观察它的歪头杀。

  

## ✨ 核心特性 (Features)

- **🎨 极致的原生级 UI 体验**
   - 基于 Material Design 3 规范设计，高质感、自适应黑暗/白天模式。
   - 精美的 3D 拟物化单设备轮播容器，支持触控滑动切换设备。
   - 全套 CSS3 丝滑过渡动画（微电波、心跳呼吸灯、高亮反馈）。
- **🧠 聪明的状态记忆**
   - 自动记忆上次使用的音箱，自动记忆上次选择的模式（原声 / TTS）。
   - 下次打开，无需重新配置，拿起就能喊！
- **🎛️ 灵活的发送控制**
   - 支持 **自动发送**（松手后 1~10 秒内自动推送，支持取消）与 **手动发送**。
   - 支持录音原声试听与“一键再次发送”。
- **🛡️ 安全与容错机制**
   - **大音量警告**：拖动音量滑块超过 80% 时触发二次确认，保护听力免受惊吓。
   - **环境检测**：自动检测 HTTPS 环境，保障麦克风录音权限安全。
   - **优雅错误处理**：对于未授权、设备离线等情况提供友好的 UI 蒙版与文字引导，拒绝冷冰冰的代码报错。
